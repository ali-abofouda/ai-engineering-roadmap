## 🌟 نظرة عامة / Overview

**AI Engineer Roadmap** هو منصة تعليمية وتوثيقية تفاعلية حديثة، أُعيد بناؤها هندسياً لتمثل مرجعاً موحداً ودقيقاً لخارطة طريق مهندس الذكاء الاصطناعي (AI / GenAI Engineer).

تم بناء محتوى الموقع بدقة بناءً على **3 كورسات تدريبية شاملة** في الذكاء الاصطناعي التوليدي، مع توثيق أرقام الأقسام والمحاضرات لكل موضوع، وتحديد نسبة التغطية:
- 🟢 **Covered (مغطى بالكامل)**
- 🟡 **Partially Covered (مغطى جزئياً)**
- 🔴 **Not Covered / Recommended External Study (غير مغطى / دراسة خارجية موصى بها)**

## ✨ المميزات الرئيسية / Key Features

- **🧭 26 Connected Stages:** مسار متكامل يمتد من البرمجة التأسيسية وهياكل البيانات وصولاً إلى النشر السحابي والـ Observability.
- **🏷️ Exact Course Citations:** كل مرحلة وكل بطاقة تعرض بادجات الكورسات المصدرية (`COURSE 01`, `COURSE 02`, `COURSE 03`).
- **📊 3-Course Coverage Matrix (`/course-coverage`):** جدول مقارنة تفاعلي يقارن أكثر من 30 كفاءة هندسية بين الكورسات الثلاثة (Strong, Partial, Missing) مع فلاتر للبحث.
- **⚠️ Gap Analysis Page (`/missing-skills`):** صفحة شفافة تفصل ما لا تزال الكورسات تفتقده (Distributed vLLM, WebSocket Streaming, Synthetic Data, Prompt Injection Defense) مقسمة حسب الأولوية.
- **📐 Interactive Architecture Visualizers:**
  - معمارية الـ RAG التفاعلية من 11 خطوة.
  - حلقة الوكلاء المستقلين (Agentic ReAct Loop) ونقاط الـ LangGraph Checkpoints.
  - محاكي التقييم ومقارنة مقاييس الاسترجاع (Recall@K, MRR, Faithfulness).
- **💼 12 Course Projects (`/projects`):** مشاريع من صلب الكورسات (Customer Churn ANN, LSTM Next Word, Groq Llama 3 RAG, Neo4j Graph RAG, Multimodal ColPali, AWS Digital Twin Terraform, Cybersecurity MCP, و ALEX Financial Multi-Agent).
- **🎯 Interview Masterclass (`/interview`):** أسئلة مقابلات تقنية متقدمة مع إمكانية إظهار الإجابات النموذجية.
- **✅ 21-Point Job Ready Rubric (`/job-ready`):** قائمة مراجعة تفاعلية لحساب جاهزيتك الوظيفية وحفظها محلياً في `localStorage`.
- **🔍 Global Instant Search (`Ctrl+K`):** بحث فوري يبحث في كل الكلمات والمحاضرات والأدوات.

## ⚠️ ما الذي لا تزال الكورسات تفتقده؟ / What Is Still Missing?

متاحة عبر المسار `/missing-skills`، مقسمة إلى 3 مجموعات مع نطاق الدراسة ومصادر خارجية مقترحة:
1. **Must Study Before Applying:**
   - Distributed High-Throughput LLM Serving (vLLM, TGI, PagedAttention, Continuous Batching)
   - Real-time Streaming WebSockets & SSE backpressure
   - Production Prompt Injection Defense (indirect injection, tool poisoning)
2. **Recommended for Mid-Level:**
   - Synthetic Data Generation & Distillation Pipelines
   - Advanced Vector Index Tuning (HNSW M/efConstruction, IVFFlat)
   - Cost Engineering & Token Caching (Prompt Caching, Semantic Caching)
3. **Advanced / Architectural Scope:**
   - Cross-Cloud Failover & Dynamic Routing
   - Fine-Tuning Evaluation & Catastrophic Forgetting Auditing

## 🚀 تشغيل المشروع محلياً / Local Development

### 1. المتطلبات الأساسية
- Node.js (v18+ أو v20+)
- npm (v9+)

### 2. تثبيت الحزم
```bash
npm install
```

### 3. تشغيل خادم التطوير
```bash
npm start
```
افتح المتصفح على: `http://localhost:4200`

### 4. بناء نسخة الإنتاج
```bash
npm run build
```
المخرجات ستكون في المجلد: `dist/ai-engineer-roadmap/`

## ☁️ النشر على Vercel / Deployment Guide

تم إعداد المشروع مسبقاً ليعمل مباشرة على **Vercel** من خلال ملف `vercel.json` لإعادة توجيه مسارات الـ SPA:

```json
{
  "version": 2,
  "routes": [
    {
      "handle": "filesystem"
    },
    {
      "src": "/.*",
      "dest": "/index.html"
    }
  ]
}
```

للنشر:
1. ارفع الكود إلى GitHub.
2. استورد المستودع في [Vercel](https://vercel.com).
3. اختر Framework Preset: **Angular**.
4. اضغط **Deploy**.
